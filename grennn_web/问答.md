# 绿色生活环保问答与商品兑换页面说明文档

## 1. 功能概述

本功能用于在 GreenSight-绿我同行 项目中新增一个“绿色生活问答”模块和一个“积分兑换商品”模块。

用户通过回答环保知识问题，学习绿色生活、垃圾分类、低碳出行、节能减排等知识。答题过程中，系统根据用户表现发放积分、徽章或抽奖机会。用户获得的积分可以进入兑换商城，兑换环保相关商品或虚拟奖励，从而形成“学习知识 -> 获得奖励 -> 兑换商品 -> 继续参与”的正向循环。

该模块适合用于比赛演示，因为它不仅能展示环保教育价值，也能展示用户激励体系、积分体系、成就体系和页面交互设计。

## 2. 建设目标

### 2.1 用户目标

- 让用户用轻松的答题方式学习环保知识。
- 让用户在获得知识的同时获得积分、徽章、优惠券等奖励。
- 让用户通过兑换商品感受到参与环保行动的真实反馈。
- 提升用户持续使用系统的动力。

### 2.2 项目目标

- 丰富项目功能模块，补齐“环保知识教育”场景。
- 与已有的积分、成就、志愿活动等功能形成联动。
- 提升项目完整度，让系统从“展示型应用”变成“可参与、可成长、可兑换”的环保平台。
- 方便后续扩展题库、活动、商品和排行榜。

## 3. 页面规划

建议新增两个核心页面：

| 页面名称 | 推荐路由 | 页面作用 |
| --- | --- | --- |
| 绿色生活问答页 | `/quiz` | 用户答题、获取积分、查看每日任务 |
| 积分兑换商城页 | `/store` 或 `/redeem` | 用户使用积分兑换环保商品 |

也可以在现有成就页 `/achievements` 中增加入口，展示“去答题赚积分”和“去商城兑换”的按钮。

## 4. 绿色生活问答页设计

### 4.1 页面定位

绿色生活问答页是一个环保知识互动页面，核心不是单纯考试，而是让用户通过轻量化的题目学习正确的环保行为。

页面应该给用户一种“每天来答几题，顺手变得更懂环保”的感觉。

### 4.2 页面结构

页面建议包含以下区域：

1. 顶部信息区

展示页面标题、用户当前积分、今日答题进度、连续答题天数。

示例文案：

```text
绿色生活问答
每天 5 道题，学习环保知识，获得绿色积分。
```

可展示数据：

- 当前积分：例如 `1280`
- 今日完成：例如 `3 / 5`
- 连续答题：例如 `7 天`
- 今日最高正确率：例如 `80%`

2. 每日问答卡片

这是页面核心区域，用卡片形式展示当前题目。

题目类型建议包括：

- 单选题
- 多选题
- 判断题
- 情景选择题

题目示例：

```text
以下哪种垃圾属于可回收物？
A. 废旧报纸
B. 剩菜剩饭
C. 用过的纸巾
D. 烟蒂
```

答题后展示：

- 正确或错误反馈
- 正确答案
- 简短知识解释
- 本题获得积分

反馈文案示例：

```text
回答正确！废旧报纸属于可回收物，回收后可以重新制浆造纸。
获得 +10 绿色积分。
```

3. 知识解释区

每道题答完后给出一段“环保小知识”，避免用户只刷分不学习。

解释内容建议控制在 1 到 3 句话，语言通俗易懂。

示例：

```text
可回收物是指适宜回收利用和资源化利用的生活废弃物。
常见可回收物包括纸类、塑料、玻璃、金属和织物。
```

4. 答题进度区

显示用户当前处于第几题。

示例：

```text
第 3 / 5 题
```

可以使用进度条增强反馈。

5. 今日奖励区

显示今日完成问答后可获得的奖励。

建议奖励规则：

- 每答对 1 题：+10 积分
- 答错但完成学习解释：+3 积分
- 每日完成 5 题：额外 +20 积分
- 全部答对：额外 +50 积分
- 连续答题 7 天：获得“绿色知识达人”徽章

6. 历史成绩区

展示最近答题记录：

- 日期
- 答题数量
- 正确率
- 获得积分

示例：

| 日期 | 正确率 | 获得积分 |
| --- | --- | --- |
| 2026-05-18 | 80% | +70 |
| 2026-05-17 | 100% | +120 |

7. 分类挑战区

用户可以选择不同环保主题进行挑战。

推荐分类：

- 垃圾分类
- 低碳出行
- 节水节电
- 绿色饮食
- 旧物利用
- 生态保护

每个分类可显示题目数量和完成状态。

## 5. 问答玩法规则

### 5.1 基础答题规则

- 用户每天默认获得 5 道每日题目。
- 每道题只能提交一次答案。
- 提交后立即显示对错和解析。
- 用户完成当天全部题目后，可以领取每日完成奖励。
- 未完成的题目可以继续答，但刷新页面后应保留答题进度。

### 5.2 积分规则

建议积分规则如下：

| 行为 | 积分 |
| --- | --- |
| 答对 1 道题 | +10 |
| 答错但查看解析 | +3 |
| 完成每日 5 题 | +20 |
| 每日 5 题全对 | 额外 +50 |
| 连续答题 3 天 | +30 |
| 连续答题 7 天 | +100 + 徽章 |

说明：

- 积分应计入用户总积分，可用于兑换商城。
- 每日答题奖励建议有上限，防止重复刷分。
- 如果题库支持随机抽题，应记录当天已回答题目，避免刷新重复获得奖励。

### 5.3 徽章规则

可新增以下问答相关徽章：

| 徽章名称 | 获得条件 |
| --- | --- |
| 环保初学者 | 首次完成每日问答 |
| 分类小能手 | 垃圾分类专题正确率达到 80% |
| 低碳达人 | 低碳出行专题完成 10 题 |
| 绿色知识达人 | 连续答题 7 天 |
| 环保满分王 | 单日问答全部答对 |

徽章可以展示在成就页中，也可以在问答页面完成时弹窗提示。

## 6. 奖品与奖励设计

奖励分为三类：积分奖励、虚拟奖励、实物或模拟商品奖励。

### 6.1 积分奖励

积分是最基础的奖励，用于连接问答页和兑换商城。

积分来源：

- 答题获得
- 志愿活动获得
- 旧物重构获得
- 社区互动获得
- 每日签到获得

积分用途：

- 兑换环保商品
- 兑换虚拟徽章
- 参与抽奖
- 解锁特殊称号

### 6.2 虚拟奖励

适合比赛演示，不需要真实库存。

示例：

- 专属头像框
- 环保称号
- 绿色徽章
- 个人主页装饰
- 环保等级提升

### 6.3 商品奖励

商品可以设置为模拟兑换，也可以作为未来真实功能扩展。

推荐商品：

| 商品 | 类型 | 兑换积分 |
| --- | --- | --- |
| 环保帆布袋 | 实物 | 500 |
| 可重复使用水杯 | 实物 | 800 |
| 竹纤维餐具套装 | 实物 | 1200 |
| 垃圾分类贴纸 | 实物 | 200 |
| 绿色知识达人徽章 | 虚拟 | 300 |
| 低碳生活头像框 | 虚拟 | 400 |
| 公益树苗认养证书 | 虚拟/公益 | 1500 |

## 7. 积分兑换商城页设计

### 7.1 页面定位

兑换商城页用于展示用户可以用绿色积分兑换的商品和奖励。

页面应该体现环保、清爽、可信赖的感觉，不建议做成普通电商促销风格，而是更像“环保奖励中心”。

### 7.2 页面结构

1. 顶部积分卡片

展示用户当前积分和兑换说明。

示例：

```text
我的绿色积分：1280
积分可通过问答、志愿活动、旧物重构和社区互动获得。
```

2. 商品分类筛选

分类建议：

- 全部
- 实物商品
- 虚拟徽章
- 头像装饰
- 公益证书
- 限时兑换

3. 商品列表

每个商品卡片展示：

- 商品图片或图标
- 商品名称
- 商品简介
- 所需积分
- 库存状态
- 兑换按钮

商品卡片示例：

```text
环保帆布袋
可重复使用，适合购物、通勤、日常收纳。
500 积分
[立即兑换]
```

4. 商品详情弹窗

点击商品后显示：

- 商品介绍
- 兑换条件
- 所需积分
- 是否限量
- 兑换后说明
- 确认兑换按钮

5. 兑换记录区

展示用户已兑换商品：

| 时间 | 商品 | 消耗积分 | 状态 |
| --- | --- | --- | --- |
| 2026-05-18 | 环保帆布袋 | -500 | 已兑换 |

6. 积分获取入口

商城底部或侧边显示“去赚积分”的入口：

- 去每日问答
- 去志愿活动
- 去旧物重构
- 去社区发布环保动态

### 7.3 兑换规则

- 用户积分不足时，兑换按钮置灰，显示“积分不足”。
- 商品有库存时才允许兑换。
- 兑换成功后扣除对应积分。
- 兑换成功后生成兑换记录。
- 虚拟商品兑换后立即到账。
- 实物商品在比赛演示中可显示“已提交兑换申请”。

### 7.4 兑换成功反馈

兑换成功后建议弹窗显示：

```text
兑换成功！
你已成功兑换“环保帆布袋”，消耗 500 绿色积分。
感谢你用知识和行动支持绿色生活。
```

如果是虚拟奖励：

```text
兑换成功！
“低碳生活头像框”已加入你的个人装饰。
```

## 10. UI 设计建议

### 10.1 问答页视觉风格

建议风格：

- 背景保持项目现有玻璃拟态和绿色主题。
- 问答卡片使用清晰边框和轻微阴影。
- 正确答案用绿色反馈。
- 错误答案用红色或橙色反馈。
- 解析区使用浅绿色或浅蓝色背景，强调“知识收获”。

问答按钮状态：

| 状态 | 表现 |
| --- | --- |
| 未选择 | 白底、浅边框 |
| 选中 | 绿色边框、浅绿色背景 |
| 正确 | 绿色背景、白色文字 |
| 错误 | 红色背景、白色文字 |
| 禁用 | 灰色、不可点击 |

### 10.2 商城页视觉风格

建议风格：

- 不做强促销电商风，更偏环保奖励中心。
- 商品卡片保持简洁，突出商品、积分和兑换按钮。
- 商品图片建议使用真实环保物品图片或统一插画风格。
- 积分卡片可以放在页面顶部，增强用户兑换动力。

## 11. 交互流程

### 11.1 问答流程

```text
进入问答页
-> 查看今日任务
-> 开始答题
-> 选择答案
-> 提交答案
-> 查看正确答案和解析
-> 获得积分
-> 进入下一题
-> 完成全部题目

-> 跳转兑换商城或继续挑战专题
```

### 11.2 兑换流程

```text
进入兑换商城

-> 确认兑换
-> 扣除积分
-> 生成兑换记录
-> 显示兑换成功反馈
```

## 12. 示例题库

### 12.1 垃圾分类

1. 废旧报纸属于哪类垃圾？

- A. 可回收物
- B. 厨余垃圾
- C. 有害垃圾
- D. 其他垃圾

答案：A

解析：废旧报纸属于可回收物，可以回收后重新制浆造纸。

2. 废旧电池通常属于哪类垃圾？

- A. 可回收物
- B. 厨余垃圾
- C. 有害垃圾
- D. 其他垃圾

答案：C

解析：废旧电池中可能含有重金属等有害物质，应按有害垃圾投放。

### 12.2 低碳出行

1. 以下哪种出行方式更低碳？

- A. 短距离开私家车
- B. 步行或骑自行车
- C. 怠速停车等待
- D. 单人长距离开车

答案：B

解析：步行和骑自行车几乎不产生直接碳排放，是短距离出行的低碳选择。

### 12.3 节水节电

1. 以下哪种行为有助于节约用电？

- A. 电器不用时保持待机
- B. 长时间开空调不关窗
- C. 离开房间随手关灯
- D. 白天开灯不开窗

答案：C

解析：随手关灯可以减少不必要的电力消耗，是简单有效的节能行为。

### 12.4 绿色饮食

1. 以下哪种行为更符合绿色饮食理念？

- A. 按需点餐，减少浪费
- B. 每餐大量剩饭
- C. 频繁使用一次性餐具
- D. 只购买过度包装食品

答案：A

解析：按需点餐可以减少食物浪费，也能降低食物生产和处理过程中的资源消耗。

## 13. 后续扩展方向

后续可以继续扩展：

- 增加 AI 出题功能，根据用户薄弱主题生成题目。
- 增加好友排行榜，展示答题积分排名。
- 增加限时挑战，例如“世界环境日专题问答”。
- 增加错题本，让用户复习曾经答错的环保知识。
- 增加兑换商品库存管理。
- 增加后台题库管理系统。
- 增加真实地址填写和兑换物流状态。

## 14. 比赛展示亮点

该功能在比赛展示中可以重点说明：

- 它把环保知识学习游戏化，降低用户参与门槛。
- 它用积分和兑换机制提升用户持续参与度。
- 它与志愿活动、成就徽章、个人积分形成完整闭环。
- 它不仅是页面展示，也体现了环保教育和行为激励的产品思路。

一句话总结：

```text
绿色生活问答让用户在学习环保知识的同时获得积分奖励，积分又可以在兑换商城中兑换环保商品，从而形成知识学习、行为激励和绿色消费的完整闭环。
```
