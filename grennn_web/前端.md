# Green Web 前端项目文档

本文档详细介绍了 Green Web 前端项目的技术栈、架构设计、功能模块及开发指南。

## 1. 项目概述

**项目名称**: Green Web (grennn_web)  
**项目描述**: 一个专注于环保和可持续生活的 Web 应用，旨在通过 AI 助手、社区互动和旧物重构等功能，引导用户践行绿色生活方式。  
**当前版本**: 0.0.0

## 2. 技术栈 (Tech Stack)

本项目采用现代化的前端技术栈构建：

*   **核心框架**: [Vue 3](https://vuejs.org/) (Composition API)
*   **构建工具**: [Vite](https://vitejs.dev/)
*   **状态管理**: [Pinia](https://pinia.vuejs.org/)
*   **路由管理**: [Vue Router 4](https://router.vuejs.org/)
*   **UI 组件库**: [Element Plus](https://element-plus.org/)
*   **CSS 框架**: [Tailwind CSS 4](https://tailwindcss.com/)
*   **HTTP 请求**: Axios
*   **Markdown 渲染**: marked
*   **动画库**: GSAP
*   **进度条**: NProgress

## 4. 快速开始 (Getting Started)

### 环境要求
*   Node.js >= 20.19.0

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```
项目将在 `http://localhost:5173` (默认端口) 启动。

### 构建生产版本

```bash
npm run build
```

## 5. 核心功能模块 (Key Features)

### 5.1 用户认证 (Auth)
*   **路径**: `/auth/login`, `/auth/register`
*   **功能**:
    *   用户登录与注册。
    *   表单验证（邮箱格式、密码长度）。
    *   **交互优化**: 支持密码显示/隐藏切换，实时输入反馈。

### 5.2 AI 助手 (Chat)
*   **路径**: `/chat`
*   **功能**:
    *   基于 GLM-4.7 模型的智能对话助手。
    *   支持流式响应 (Stream) 渲染 Markdown 内容。
    *   **交互优化**:
        *   空状态下提供快捷提问建议卡片。
        *   支持“换一换”随机推荐问题。
        *   消息自动滚动到底部。
        *   支持停止生成、重新生成和复制回答。

### 5.3 社区互动 (Community)
*   **路径**: `/community`
*   **功能**:
    *   用户动态流 (Feed) 展示。
    *   点赞与评论功能。
    *   **交互优化**:
        *   图片灯箱预览 (Lightbox)：点击图片全屏查看。
        *   分享功能：点击分享按钮复制动态链接。
        *   点赞动画反馈。

### 5.4 旧物重构 (Reconstruction)
*   **路径**: `/reconstruction`
*   **功能**:
    *   上传旧物图片，AI 分析并生成改造方案。
    *   支持文件拖拽上传。
    *   **交互优化**:
        *   文件类型校验 (仅限图片) 与大小限制 (5MB)。
        *   模拟 AI 分析过程动画 (扫描、识别材质、计算碳减排)。
        *   展示重构建议与制作步骤。

### 5.5 全局交互
*   **导航**: 响应式导航栏，支持移动端适配。
*   **反馈**: 使用 `ElMessage` 进行全局操作反馈（成功/失败提示）。
*   **加载**: 页面切换时顶部显示 NProgress 进度条。

## 6. 状态管理 (State Management)

项目使用 Pinia 进行状态管理，主要 Store 如下：

### User Store (`stores/user.js`)
*   **State**:
    *   `user`: 用户信息 (名称、邮箱、积分、等级)。
    *   `badges`: 徽章成就列表。
    *   `chatHistory`: 聊天记录持久化。
*   **Actions**:
    *   `init()`: 从 localStorage 初始化数据。
    *   `addPoints(amount)`: 增加积分。
    *   `unlockBadge(badgeId)`: 解锁徽章。
    *   `saveChat(messages)`: 保存聊天记录。

## 7. 配置与代理 (Configuration)

### Vite 代理 (`vite.config.js`)
项目配置了 API 代理以解决跨域问题，并注入 API Key：

```javascript
server: {
  proxy: {
    '/siliconflow-api': {
      target: 'https://api.siliconflow.cn',
      changeOrigin: true,
      // ... 自动注入 Authorization 头
    },
  },
}
```

## 8. 样式系统 (Styling)

*   **Tailwind CSS**: 用于大部分布局和原子样式 (如 `flex`, `p-4`, `text-center`)。
*   **Element Plus**: 用于复杂交互组件 (Dialog, Icon, Message)。
*   **自定义样式**: `assets/main.css` 中包含部分全局样式和过渡动画定义 (如 `.fade-enter-active`)。

## 9. 开发规范

*   **组件命名**: 采用 PascalCase (如 `ChatView.vue`, `BaseButton.vue`)。
*   **目录结构**: 视图组件放 `views/`，通用组件放 `components/`。
*   **图标**: 统一使用 `@element-plus/icons-vue`。
